# Fonts

`NotoSansLinearA-Regular.ttf` — Noto Sans Linear A, version 2.000, Copyright
2017 Google Inc., licensed under the SIL Open Font License 1.1 (`OFL.txt`).
Obtained from the lineara.xyz repository, where it ships as
`assets/NotoSansLinearA-LinearB.ttf`.

Verified coverage: 342 characters in the Linear A block (U+10600–U+1077F) and
57 in Aegean Numbers (U+10100–U+1013F). One font covers both ranges, so no
second font is needed — Noto Sans Symbols 2 covers neither and was dropped.

Not yet subset. `pyftsubset` over the two ranges would cut the 118 KB further.
